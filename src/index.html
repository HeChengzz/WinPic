使用文档

浏览

打开照片 Enter 或 Space（光标在卡片上时）
上一张 / 下一张 A ←  ·  D →
缩放 滚轮  ·  + -
精细缩放 Shift + 滚轮

旋转

逆时针 90° W 或 ↑
顺时针 90° S 或 ↓
慢速旋转（按住） Shift + W / S
保存旋转结果 查看器顶部「保存旋转」按钮

重置与关闭

重置缩放 / 位移 / 旋转 R 0 或双击图片
关闭查看器 Esc

文件操作

导入 点击左侧「目录」右侧的 + 按钮
刷新目录 点击「目录」右侧的刷新按钮
收藏 悬停缩略图，点击右上角爱心
重命名 / 移动 / 删除 查看器顶部对应按钮
设为壁纸 查看器顶部「设为壁纸」

支持的图片格式

常见格式 png · jpg · jpeg · gif · webp · bmp · svg · avif · ico · tiff
不支持保存旋转 gif · svg

关于

WinPic

版本 0.1.0

一款轻量的本地图库工具，专注于浏览与管理本地照片。 支持多目录导入、缩略图缓存、旋转、移动、删除到回收站等常用操作。

技术栈

桌面框架 Tauri 2
前端 原生 HTML · CSS · JavaScript
后端 Rust
图片处理 image crate

数据说明

应用仅在本机保存图片路径与偏好设置（localStorage）， 不会上传、修改或删除你的原始文件——除了你在应用内显式执行的操作（重命名、旋转、移动、删除到回收站）。
